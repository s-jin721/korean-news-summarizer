# Korean News Summarizer (KoBART 기반 한국어 뉴스 요약기)

이 프로젝트는 한국어 뉴스 기사를 입력하면 KoBART 한국어 요약 모델을 사용해서
자동으로 요약문을 만들어 주는 콘솔 프로그램입니다.

긴 기사도 여러 조각으로 나누어 순차적으로 요약하고,
요약 길이, 압축 비율, 단어 겹침 비율 등을 함께 출력합니다.
또한 요약 결과를 CSV 로그 파일로 저장합니다.

--------------------------------
1. 프로젝트 정보
--------------------------------

- 프로젝트 이름: News Summarizer
- 기능: 한국어 뉴스 기사 요약
- 사용 언어: Python
- 사용 모델: KoBART (gogamza/kobart-summarization)

--------------------------------
2. 사용한 오픈소스 및 모델
--------------------------------

- Python 3.x
- PyTorch (torch)
- Hugging Face Transformers (transformers)
- 한국어 요약 모델: "gogamza/kobart-summarization" (Hugging Face Hub에서 제공)

각 라이브러리와 모델의 자세한 라이선스는
해당 프로젝트의 공식 페이지(GitHub, Hugging Face 등)를 참고했습니다.

--------------------------------
3. 설치 방법
--------------------------------

1) 이 저장소를 클론하거나 압축을 다운로드해서 풀어 줍니다.

2) 필요한 라이브러리를 설치합니다.
   (같은 폴더에 requirements.txt 파일이 있다고 가정)

   터미널 또는 명령 프롬프트에서:

   pip install -r requirements.txt

   requirements.txt 내용이 단순하다면 아래처럼 직접 설치해도 됩니다.

   pip install torch transformers

5. 로그 파일 (logs/summary_log.csv)
--------------------------------

프로그램이 정상적으로 동작하면 logs 폴더 안에 summary_log.csv 파일이 생성됩니다.

각 요약 실행마다 다음 정보가 한 줄씩 추가됩니다.

- 실행 시각 (timestamp)
- 사용한 요약 모드 이름 (예: "기본 요약")
- 원문 길이 (문자 수, 단어 수)
- 요약 길이 (문자 수, 단어 수)
- 압축 비율
- 단어 겹침 비율
- 요약 앞부분 미리보기 (약 80자)

이 파일을 통해 여러 기사에 대한 요약 결과를 비교하거나
요약 길이와 품질을 간단하게 분석할 수 있습니다.

--------------------------------
6. 한계 및 주의 사항
--------------------------------

- 긴 기사에서 여러 인물, 숫자, 사건이 섞여 있을 경우
  서로 다른 문단의 정보를 한 문장에 섞어 쓰는 현상(hallucination)이 나타날 수 있습니다.

- 날짜, 금액, 길이, 인물 이름, 기관 이름 등의 숫자와 고유명사가
  원문과 다르게 요약되는 경우가 있습니다.

- 드물게 ". , . ." 와 같은 의미 없는 문장부호가 반복되는 문장이 생성되기도 합니다.

따라서 이 프로그램이 만들어 내는 요약은
최종 완성본이라기보다 "초안(draft)" 정도로 보는 것이 좋습니다.
실제 사용 시에는 사람이 내용을 한 번 검토해주는 것이 안전합니다.

--------------------------------
7. 향후 개선 아이디어
--------------------------------

- 뉴스 기사 URL을 입력하면 웹 페이지에서 본문을 자동으로 추출해서 요약하기
- Tkinter, Flask, Streamlit 등을 이용한 GUI 또는 웹 인터페이스 추가
- 다른 한국어 요약 모델과 비교 실험
- 후처리(post-processing)를 이용해 문장부호/띄어쓰기 정리
- ROUGE 같은 정량적인 요약 품질 지표 도입
